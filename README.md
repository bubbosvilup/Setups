# 📦 Project Setups

Due setup base pronti all'uso:

## ▶️ Vanilla JS Setup

```bash
git clone https://github.com/bubbosvilup/Setups.git
cd Setups/vanillaSetup
npm install
```

## ⚛️ React + Vite Setup

```bash
git clone https://github.com/bubbosvilup/Setups.git
cd Setups/reactSetup
npm install
npm run dev
```

Clona la repo una volta, copia la cartella che ti serve, e rinominala per iniziare un nuovo progetto.
