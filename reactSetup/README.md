# React + Vite + ESLint + Prettier Boilerplate

Un setup moderno e minimale per partire con progetti React.

## ✅ Include

- **React 18**
- **Vite** (dev server veloce + build ottimizzata)
- **ESLint** con:
  - `eslint-plugin-react`
  - `eslint-plugin-react-hooks`
  - `eslint-plugin-prettier`
- **Prettier** (auto-formatting del codice)
- Struttura modulare: `components/`, `pages/`, `assets/`

## 🛠 Come usarlo

```bash
npm install
npm run dev
```

## 📦 Script utili

```bash
npm run dev # Avvia il dev server Vite
npm run build # Crea la build di produzione
npm run preview # Anteprima build
npm run lint # Linting del progetto
npm run lint:fix # Linting + fix automatico
```

## 📁 Struttura progetto

```bash
src/
├── assets/
├── components/
├── pages/
├── App.jsx
└── main.jsx
```

# 📌 Note

Puoi usare questo progetto come base clonandolo ogni volta che inizi un nuovo progetto React.
